# FreeAim 设计记录：四点瞄准模型

最后更新：2026-11-17，对应 `FreeAim.Client` 0.0.22。
本文记录"为什么这样设计"和与用户讨论后定下的决定。代码结构、引擎事实和构建步骤见 `../AGENTS.md`，版本历史见 `CHANGELOG.md`。

## 1. 目标

追求写实的持枪手感，而不是单纯削弱：
- 子弹沿枪口飞，枪口指向和屏幕中心可以不一致。
- 枪有重量：重枪、长枪转得慢、停得柔，人机效率高的枪更跟手。
- 身体的呼吸、步伐会带着枪晃，手臂去修正它。
- 据枪（战术准备姿态）用上肢耐力换稳定和居中准星。
- 后坐力永远不被削弱。
- 写实不等于削弱：如果写实的结果比原版更强（例如腰射慢晃被手臂修掉），可以接受。

## 2. 四个点

所有角度都相对视角中心 V，单位度：x = 偏航（右为正），y = 俯仰（下为正）。

| 点 | 含义 | 怎么动 |
|---|---|---|
| **V 视角** | 头的朝向，也就是屏幕中心 | 鼠标直接控制，灵敏度和原版完全一致。偏航相对身体 A 在"脖子范围"内自由转；超出后，V 的转速不能超过身体的转速，多出的鼠标输入丢弃 |
| **A 身体** | 身体让枪指的方向，也是手臂的基座 | 偏航带着最大转速去追 V（头先转、躯干后到）；俯仰等于 V。呼吸、步伐等身体晃动 D 从这里进入 |
| **T 期望** | 枪口想去的位置 | T = V + 领先偏移 O。转向时 T 比 V 快（领先倍数），停下后部分保留、部分回落；鼠标 5 秒不动，枪慢慢回到屏幕中心 |
| **R 枪口** | 子弹实际飞的方向 | 手臂（非刚性连接）把 R 送向 T，带着枪的惯性。追不上 T 就是"甩不动"的感觉 |

速度关系：转向时 **R（枪口）> V（视角）> A（身体）**。

## 3. 已定的设计决定

| 话题 | 决定 | 说明 |
|---|---|---|
| 鼠标控制谁 | 鼠标控制视角 V | 旧版鼠标先推枪、镜头只拿 15%，违反直觉 |
| 停下后的领先 | 混合：一部分保留，一部分回落；鼠标静止 5 秒后枪回到屏幕中心 | 瞄准、对枪时不会 5 秒不动，所以回正不影响战斗 |
| 身体限制视角 | 脖子范围 45°（和游戏自身的身体-视角 45° 一致），身体转速 300°/s（参考枪站立） | 转速随枪惯性、蹲姿、超重、腿伤降低。俯仰不限制 |
| 开镜 | 枪口 R 追视角 V | 准星偏了会滑回中心；不再"镜头转向枪口" |
| 据枪 | 身体撑稳（D × 0.5）、O → 0（T 对齐 V）、手臂绷紧（×1.5）、I 项打开、消耗上肢耐力 | 不完全对准：仍保留一半呼吸和走动偏移 |
| 游戏自带转向晃动 `SwaySpring` | 扣掉 | 由我们的手臂惯性代替，避免重复惩罚 |
| 身体晃动 D | 从游戏 `HandsRotation` 弹簧读出后扣掉，再作为 A 的扰动经过手臂 | 不在弹簧里的部分（走路手臂动画、腰射随机游走）无法改道，原样保留 |
| κ（枪的惯性挡快抖） | 做 | 重枪把步伐、手抖过滤得更平滑 |
| 重枪走路晃动放大（共振） | 先不做 | 晃动路径保证增益 ≤ 1。以后结合"准备姿态"再做 |
| 修正比例 g（腰射看不准所以少修） | 不做 | 腰射比原版稳，接受 |
| 过冲 | 手臂本身不过冲；0.0.24 起由"枪身甩动"单独负责，只冲一次 | 0.0.20–0.0.21 的欠阻尼弹簧像果冻。0.0.23 的积分在转向时累积过头（±3°，所有枪一样），用户认可这个幅度用在重枪上，但不能和新的过冲叠加，所以积分加防累积，过冲改由枪身甩动按武器给出。纯"手臂力量上限"模拟后放弃：过冲像悬崖，要么 0 要么 15–30° |

### 高、低准备姿态

- Ctrl + Mouse4 进入低准备，T 默认比 V 低 20°；Alt + Mouse4 进入高准备，T 默认比 V 高 25°。两者沿用据枪的切换／按住设置，可以直接切换，也会在开镜、冲刺和换弹等手部动作时暂时收起。
- 两种姿态默认将 A 追随 V 的速度和转速上限乘以 1.25。低准备将游戏允许的上肢自然恢复率乘以 1.5，仍受原有恢复冷却和容量限制。空耐力可以进入低准备。
- 低准备步行移速默认乘以 1.10。加成作用于游戏按速度档位和状态计算出的步行位移；开镜、冲刺和低准备暂停期间立即停用，姿态恢复后重新生效。
- 退出低准备或从低准备直接开镜时，参考枪的抬枪时间单独设为 0.70 秒，仍按武器缩放。直接开镜时，镜头贴向瞄具的进度受抬枪进度限制，步行加成仍立即取消。进入低准备的下压时间和 A 的跟随倍率沿用原来的过渡。
- 姿态角平滑加入 T，R 仍由手臂模型跟随。手臂俯仰可动范围围绕姿态角移动。
- 右肩高准备时，在原版手部 IK 求解前平移整把枪：默认从原位置下移 18 厘米、右移 6 厘米。按两只手的可达范围限制平移量，两肘沿用原版的弯曲方向，镜头和上抬角不变。

## 4. 手臂模型（0.0.22）

每帧在武器动画阶段（`ApplyComplexRotation` 后缀）运行：

1. **目标**：T = O + 重力下垂（向下）+ 积分项 Hold。
2. **目标平滑**（一阶，时间 τs）：起步、停下都是渐变，解决"加速减速过快"。τs 按枪惯性放大。
3. **临界阻尼弹簧**（阻尼比固定为 1，ω 按枪调整）追平滑后的目标，带部分目标速度前馈：
   `k = 1 − 1/(2·ω·τs)`
   这个 k 保证转向停下时驱动项不变号，所以不会过冲；同时减少转动中的落后。
4. **视角转动时枪保持世界方向**（每帧先减去视角变化），所以转动时枪被拖在后面。
5. **手臂摆动范围**：枪相对身体最多偏航 30°、俯仰 15°。
6. **积分项 I**（据枪和开镜时）：积分"期望 − 枪"，顶住重力下垂和持续偏斜。时间常数按枪惯性和上肢疲劳变慢。0.0.24 起按轴防累积：视角或枪转速 > 10°/s、枪口离手臂目标 > 1.5°、或枪身甩动 > 0.3° 时该轴暂停。
7. **枪身甩动**（0.0.24）：Swing'' + 2ω·Swing' + ω²·Swing = −g·(手臂加速度)，临界阻尼。g = 0.4 × scale^0.5，ω = 2π × 1.2 Hz / scale，scale = J^0.5 / 人机系数；上限 4°。加速时枪往后甩，停下时冲过去一次。模拟 150°/s 停下：冲锋枪 0.5°，参考枪 1.0–1.3°，长枪 1.6–2.8°，机枪 1.9–3.6°，回摆约 0.03°。
8. **晃动路径**（与手臂并联，增益 ≤ 1）：D × (1 − 撑稳) 先被手臂以 ω 高通（慢的修掉），剩下的快晃有 κ 的比例被惯性低通平滑。
9. **输出**：R = 手臂 + 枪身甩动 + 晃动，乘以权重（模型不活动时淡出），按游戏自己的 `RotationCenter` 旋转武器。
10. **后坐力**：模型从不测量枪口，看不到后坐力，不可能修掉它。

模拟（150°/s 转 0.4 秒后停，0.0.22 手臂本身）：所有枪 0 过冲。转动中最大落后：手枪 14°，参考枪 28°，3.9 kg/1.26 m 42°，7.4 kg 机枪 46°。落后与转速成正比，领先偏移和手臂范围会部分抵消、封顶。

## 5. 按武器的参数

输入（每 0.5 秒或换枪时读取）：总重 m（含配件、弹匣），枪长 L（基准点到枪口，含消音器，不含枪托），总人机效率（含技能，手臂受伤为 0）。

- 转动惯量比 `J`：按配件重量和位置实测惯量，除以参考惯量 `m₀·L₀²/3`；无法测量时用 `m·L²/(m₀·L₀²)`。参考枪 `m₀ = 3.5 kg`，`L₀ = 0.8 m`。
- 手感倍率 `S = J^a × (m/m₀)^(a·w)`，默认惯量指数 `a = 0.5`，额外枪重权重 `w = 0.08`。总重的有效指数为 0.54（较 0.1.1 的 0.60 低 10%），枪长和配件位置的指数不变。
- 人机系数：人机 20→80 对应 ×0.80→×1.20
- 手臂响应 ω = 基础 Hz / S × 人机系数（限制 1.2–10 Hz）
- 目标平滑 τs = 0.12 s × S / 人机系数
- 身体转速 × 1/S（限制 0.4–1.5）
- κ = J / (J + 1)
- 重力下垂 × (m·L)/(m0·L0)，上肢越累越大
- 积分时间常数 τ = 1.2 s × S / 人机系数 × (1 + 1.5·(1 − 上肢耐力比例))

## 6. 测量数据（0.0.16 探针，右肩，平地，上肢满）

单位度，P 正 = 枪口偏下，Y 正 = 偏右。原始日志和脚本在 `C:/Users/Administrator/scratch/sway/`。

| 动作 | 腰射枪口平均 | 据枪枪口平均 |
|---|---|---|
| 站立 | P 0.4，慢慢游走 ±0.5~1 | P 0.07 |
| 向前走 | P 1.03 ±0.63 | P 0.85（旧"砍 50%"几乎没减） |
| 横移 | Y ±2.2~2.4（落后于移动方向） | Y ±1.2 |

- 镜头自身动画只在移动时上抬约 0.15°，不左右偏，偏差几乎全来自枪。
- 上肢耐力低于 20：偏下 2~4 倍，快抖约 4 倍（游戏呼吸效果器自带）。
- 游戏晃动弹簧只有 P 和 D，没有 I，所以持续推力会留下稳态偏移，这就是"枪口停在准星下面"的来源。
