# FreeAim｜让视线和枪口不必绑在一起

FreeAim 是一个适用于 **SPT 4.1.6** 的客户端持枪手感模组。最容易察觉它的时刻不是开火，而是**转头后突然停住鼠标**：你的视线已经停在门框上，手里的枪却未必正好指着门框。短而轻的武器跟得紧；同一把枪换上较重的前端配件，起步和收住的感觉也会变。

> 本文介绍当前开发版。仓库 `dist/` 中的 `FreeAim-0.1.0.zip` 是首发包，不包含后续新增的高、低准备等改动。

## 不开镜时，屏幕中心不一定是枪口方向

小幅观察时，你仍然用鼠标直接转动视角，不必等整个人一起转。转幅变大后，身体需要跟上，枪则随双臂起停。转向时它并不是永远慢半拍：轻快的武器可以略微领在视线前面，较重的武器更容易拖在后面。区别不只取决于总重，还取决于重量装在哪里，以及武器本身的人机工效。

停下鼠标后，枪口可以留在稍偏左或偏右的位置，并不表示鼠标漂移。默认 **5 秒**没有新的转视输入，保留的偏移才开始慢慢回到中心。子弹仍沿游戏里的枪口方向飞；模组没有在屏幕中央另设一个落点。

**开镜后不需要重新学一套瞄准。** 镜内瞄准、晃动和枪口后坐主要交回原版，身体大幅转向的限制仍在。不开镜射击时，模组会额外表现后坐传到视角的感觉，但不会替你抵消原版枪口后坐。

## 三种姿态，区别在哪里？

默认是**按一下进入，再按同一组合退出**。`Mouse4` 是鼠标侧键，不是键盘上的数字 4。

| 默认按键 | 姿态 | 你会看到什么 |
|---|---|---|
| **Mouse4** | 据枪 | 枪身收近并略微倾斜，原先偏在一侧的指向往中心收，晃动更稳。它不是开镜，也不是免费加成：维持姿态会消耗上肢耐力；换弹等动作会暂时打断它。 |
| **Ctrl + Mouse4** | 低准备 | 枪口放低，身体转向更容易跟上视线。完全放低后，默认步行速度提高 **10%**，上肢耐力自然恢复为 **1.5 倍**；仍需等原版恢复冷却结束。加成随动作过渡，开镜或冲刺时不享受。直接从低准备开镜，会先看到枪抬起来。 |
| **Alt + Mouse4** | 高准备 | 枪口上抬，身体转向也更跟手。右肩时双手和枪身会一起向右下方让出视野。它没有低准备的步速和耐力恢复加成。 |

**装了高瞄具，据枪时为什么还挡住一点画面？** 模组会按实际配件外形尝试让出屏幕中心，但不会为了完全清空画面，一直把双手往下拉。先保留姿态，再用双臂剩余的活动空间做居中和下移。所以换一套配件或换肩后，同一姿态在屏幕上的位置可以略有不同。

## 第一次玩，怎么试出区别？

不必先调参数。找一面有门框的墙，**不开镜**做三个动作就够了：

1. 视线从门框一侧移到另一侧，突然停住。看枪是和视线同时停，还是稍后才收住。退出姿态后按 **F8** 切换自由瞄准，再用同一把枪做一次对比。
2. 正常步行时进入低准备，再退出。留意步速是不是随双手放低、抬起而变化，而不是按键一响就换挡。
3. 装上较高的瞄具，左右肩分别进入据枪。观察双手和屏幕中心，不必把“哪一边挡得更少”当成判定姿态是否正常的标准。

## 安装、设置与卸载

- **安装：** 关闭客户端，把发行包中的 `BepInEx` 文件夹解压到 `EscapeFromTarkov.exe` 所在目录。若拿到的是单独的开发版 DLL，放到 `BepInEx/plugins/FreeAim.Client.dll`。启动游戏即可，不需要安装服务端模组。
- **改键：** 按 **F12** 打开 SPT 随附的 ConfigurationManager，在 FreeAim 的「1c. 据枪」里修改姿态键，或把切换改为按住。没有鼠标侧键也可以玩：把姿态键换为其他键，Ctrl 和 Alt 组合会跟着使用新键。
- **某把模组武器特别迟钝：** 不必先改所有枪的手感。可以在「1e. 按武器调整」里关闭「按配件位置算惯量」，用总重和枪长的简单估算做对比。不同武器和配件仍在校准，特殊模组枪的枪托识别也可能有偏差。
- **恢复默认或卸载：** 关闭客户端。只想重置设置，先备份再删除 `BepInEx/config/com.spt.freeaim.client.cfg`；要卸载，删除 `BepInEx/plugins/FreeAim.Client.dll` 即可。
