# FreeAim

SPT 4.1.6 客户端模组（BepInEx 插件）：写实的持枪手感与自由瞄准。追求的是真实感，不是削弱。

## 功能

- **四点模型**：鼠标转视角；身体转速有限，带着枪走；枪口靠手臂惯性跟随，转向时先领先、后落后，重枪甩过头一次再回正。
- **按武器区分**：跟随速度、起停、甩动、下垂、举枪时间都由游戏数据自动算出，包括总重、各配件的重量和安装位置（转动惯量）以及人机工效。模组武器和配件同样适用。
- **据枪（战术准备姿态）**：按键举枪，准星回到屏幕中心，枪收近并倾斜，身体撑稳；会消耗上肢耐力。换弹等手上动作时自动暂停，完成后自动恢复。可换到左肩。据枪时会按枪的实际外形（瞄具、支架高度）把枪放低，不挡屏幕中心。
- **高、低准备**：高准备抬枪，低准备压枪；两者都加快身体朝向 A 跟随视角 V。低准备额外加快上肢耐力恢复。
- **后坐力反馈**：每一发按子弹动量（弹头质量 × 初速，含火药气体）把视角顶起，身体被推出少量残留。有没有枪托差别很大：手枪不装枪托几乎不顶，步枪弹顶得多。新口径同样自动计算。原版的枪口后坐力完全不变。
- **开镜保持原版**：开镜后枪、晃动、后坐力都是原版的，只保留身体转速对视角的限制。

## 安装

1. 先安装 SPT 4.1.6，BepInEx 随 SPT 一起提供。
2. 把压缩包里的 `BepInEx` 文件夹解压到游戏根目录，也就是 `EscapeFromTarkov.exe` 所在的文件夹。插件位置应为 `BepInEx/plugins/FreeAim.Client.dll`。
3. 启动游戏。

卸载时删除 `BepInEx/plugins/FreeAim.Client.dll` 即可。配置文件在 `BepInEx/config/com.spt.freeaim.client.cfg`，想恢复默认设置就删掉它。

## 按键

| 按键 | 作用 |
|---|---|
| 鼠标侧键（Mouse4） | 据枪，进入或退出（也可改为按住） |
| Ctrl + Mouse4 | 低准备：枪口下压，A 跟随加快，上肢耐力恢复加快 |
| Alt + Mouse4 | 高准备：枪口上抬，A 跟随加快 |
| F8 | 模组总开关，方便和原版对比 |
| F12 | 设置菜单，需要 ConfigurationManager，SPT 自带 |

三种姿态共用 F12 →「1c. 据枪」的切换／按住设置。高、低准备的角度、身体跟随倍率和低准备的耐力恢复倍率也在这里。右肩高准备会前移握点并让左肘避开视线；可调整「右肩高准备前移（厘米）」。所有选项在 F12 菜单里都有中文名称和说明。测试用的选项（固定偏移、调试信息）需要勾选 F12 里的 "Advanced settings" 才会显示。

## 已知问题

- 0.1.0 是第一个发行版，数值还在平衡中，不同枪之间的手感差距可能偏大或偏小。
- 按配件位置计算惯量是新做的功能，还没有用大量枪械校准。如果某把枪手感明显不对，可以在 F12 → "1e. 按武器调整" 里关闭"按配件位置算惯量"，换回简单估算（总重 × 枪长²）。
- 枪托的判断依据是游戏的枪托配件类型和 `mod_stock` 插槽。不按规范命名插槽的模组武器可能判断错误。
